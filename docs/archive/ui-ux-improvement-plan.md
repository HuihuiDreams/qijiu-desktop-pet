## 一、背景与精炼 (Background & Refinement)

### 问题陈述
当前项目的“仙侠水墨风 (Xianxia Ink-Wash)”基础扎实，但在视觉颗粒度和交互深度上仍处于 MVP 阶段。主要问题包括：
1. **元素冲突**：系统级 Emoji 图标与古风审美不兼容。
2. **动效节奏优化 [Done]**：调整宠物呼吸、行走等常驻动画的步频，降低视觉疲劳。
3. **反馈单薄 [Done]**：养成行为（喂食、打坐）缺乏视觉冲击力，难以形成情感连接。
4. **装饰缺失 [Done]**：状态面板（玉简）目前仅为带背景的方框，缺乏材质细节和传统装饰元素。

### 核心假设
- **材质化升级**：~~通过强化 Glassmorphism 与水墨笔触的融合，提升界面质感。~~ 优先使用半透明纯色、静态纹理、细边框和低成本阴影来提升质感，避免大面积实时模糊。
- **动效生物化**：模拟自然界节奏（如呼吸、灵气波动），让宠物更“活”。
- **符号化语言**：使用统一的矢量线条图标代替 Emoji，构建专业的视觉语言。

### 性能评审结论（2026-05-12）
- **保留**：SVG 图标替换、静态云纹/边框、`transform`/`opacity` 驱动的短时过渡、低频呼吸节奏调整。
- **删除线处理**：大面积或常驻 `backdrop-filter`/`blur`、粒子发生器、动态 `mask-image` 流光、增强版 `shimmer`、依赖 `will-change` 硬扛的大量特效。这些方案对 Electron 桌宠的长期 CPU/GPU 占用和内存合成层压力偏高。

## 二、功能规格 (Functional Specification)

### Objective（目标）
基于 `ui-ux-pro-max-skill` 的设计智能，深度优化“七九爱宠”的视觉体系，将其从简单的工具界面升级为具有沉浸感的艺术化交互界面。

### 关键改动点与技术细节

#### 1. 视觉符号：SVG 矢量化重塑
- **改动**：全面替换 `context-menu` 中的 Emoji。
- **技术要求**：
  - 图标风格：水墨笔锋风格或极简线条（1.5px 描边）。
  - 色彩同步：使用 `--color-jade-deep` 或 `--color-ink` 变量，支持悬停时的色值变换。
  - 理由：符合 `no-emoji-icons` 准则，提升品牌独特性。

#### 2. 交互动效：灵气汇聚 (Qi Aura) 体系 [Done] ✅
- **完成记录**：已落地轻量 DOM 灵气光晕体系，覆盖进食、打坐、抚摸、休息、普通互动与双人覆盖互动；使用 `transform` / `opacity` 驱动，动画结束后自动移除节点。
- **改动**：~~在执行“喂食”、“打坐”、“修炼”等关键动作时增加粒子反馈。~~ 在关键动作时增加一次性、数量受限的轻量反馈。
- **技术要求**：
  - **灵气粒子**：~~使用 `backdrop-filter: blur(4px)` 配合 `--color-jade-glow` 的径向渐变小球。~~ 改为复用 1-3 个 DOM 节点或伪元素，仅使用 `transform` 与 `opacity` 做短时反馈。
  - **动画曲线**：采用 `cubic-bezier(0.34, 1.56, 0.64, 1)` (Back Out) 模拟灵气爆发。
  - **墨迹扩散**：~~悬停菜单项时增加类似“墨水在宣纸上晕开”的位移与渐变效果。~~ 悬停只做背景色、透明度和轻微位移变化，避免实时模糊/渐变扩散。

#### 3. 状态面板：“浮动玉简”质感增强 [Done]✅
- **改动**：为 `.status-panel` 增加材质细节。 [Done]✅
- **技术要求**：
  - **角部云纹**：使用 SVG 蒙版或 `::before/::after` 伪元素加入古风云纹装饰。 [Done]
  - **流光进度条**：~~为 `.stat-bar-fill` 增加动态 `mask-image` 流光，模拟灵气流动的视觉效果。~~ 使用静态高光或仅在数值变化时触发一次 `opacity`/`transform` 过渡。 [Done]
  - **边框工艺**：引入细微的 `inset` 阴影，模拟玉石边缘的透光感。 [Done]
  - **实现记录**：已在 `src/status.css` 与 `src/index.css` 中落地轻量版玉简质感，移除状态面板实时 `backdrop-filter`，使用静态渐变、伪元素内框、角部云纹和静态进度条高光。

#### 4. 角色状态：差异化呼吸节奏 [Done]✅
- **改动**：调整 `walkBounce` 和 `sleepBreath`。
- **技术要求**：
  - **行走周期**：从 0.4s 延长至 0.6s - 0.8s，减少视觉焦虑。 [Done]
  - **呼吸幅度**：引入微小的 `rotate` 偏移，模拟更加真实的生命律动。

## 三、任务分解 (Task Breakdown)

### Phase 1：视觉资源与样式底座
- **Task 1: 仙侠图标库构建**
  收集或设计 5 枚核心图标（喂食、修炼、抚摸、休息、状态），存储为 `src/assets/icons/` 下的 SVG 格式。
- **Task 2: 水墨滤镜与混色配置**
  在 `index.css` 中预定义交互状态滤镜，如 `grayscale(0.8)` (疲劳状态) 和 `drop-shadow(0 0 10px var(--color-jade))` (充能状态)。滤镜只用于状态切换后的静态表现，避免放入常驻关键帧动画。

- **Task 3: 动画步频调整 [Done]✅**
  修改 `index.css` 中的 `@keyframes`，将 `walkBounce` 周期延长至 0.8s，`sleepBreath` 加入微小随机性。
- **Task 4: 灵气汇聚特效与玉简升级 [Done] ✅**
  - **改造 ContextMenu.js**：~~实现“墨迹扩散”悬停效果。~~ 实现低成本悬停反馈，仅使用颜色、透明度和位移。
  - **升级 StatusBar.js (玉简系统) [Done]**：~~增加背景流光 (`shimmer` 增强版) 逻辑及~~ 增加装饰性 SVG 边框图层。已改为静态玉简质感、伪元素云纹、内边框和静态进度条高光。

### Phase 3：反馈系统与性能微调
- **Task 5: 粒子系统实现 (InteractionSystem.js) [Done] ✅**
  ~~实现一个轻量级的 CSS/JS 粒子发生器，用于生成“灵气点”。~~ 删除独立粒子发生器方案，改为少量复用节点的一次性反馈，避免频繁创建/销毁 DOM 与动画对象。
- **Task 6: 性能优化检查 [Done] ✅**

## 四、验证清单 (Verification)

- [x] **视觉质感**：面板是否呈现出玉石/宣纸的质感，而非简单的 HTML 容器。
- [ ] **动画自然度**：常驻动画在桌面运行 1 小时后，是否依然觉得舒适。
- [ ] **交互时延**：视觉反馈（~~流光/粒子~~ 轻量高光/位移反馈）是否在点击后 100ms 内触发。
- [ ] **性能预算**：桌宠闲置时 CPU 与内存是否保持稳定，交互反馈结束后是否释放临时样式和节点。
- [ ] **适配性**：在深色模式下，所有的 SVG 图标和装饰云纹是否具有足够的对比度 (>= 3:1)。

## 五、风险与缓解 (Risks & Mitigation)

| 风险 / 挑战 | 影响 | 缓解策略 |
| :--- | :--- | :--- |
| **GPU 压力** | 中 | `backdrop-filter` 较多可能导致低端机掉帧。**缓解**：在性能较低的环境下自动降级为简单的 `rgba` 颜色。 |
| **审美偏差** | 低 | 装饰元素过多可能破坏极简美学。**缓解**：严格遵循“少即是多”的水墨留白原则，所有装饰透明度控制在 0.1 - 0.2。 |
