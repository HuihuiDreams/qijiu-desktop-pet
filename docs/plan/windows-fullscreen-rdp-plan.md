# Windows 全屏 RDP 防遮挡修复

更新日期：2026-11-09。单任务修复，范围为 Windows 前台全屏 `mstsc` / `msrdc`。

目标：全屏远程桌面优先展示，宠物不被定时置顶守卫重新抬升；离开后恢复，同时保留既有手动、会议、番茄钟隐藏状态。

## 手动验收

真实 RDP 会话尚未验证：全屏后观察至少 6 秒，确认宠物不再浮出；窗口化、最小化及切回本地应用后确认恢复。关闭窗口感知行走后重复；先手动隐藏宠物时，恢复本地桌面也应保持隐藏。

检测响应取决于既有采样周期；多屏时临时隐藏整个主透明窗口，第三方内嵌 RDP 客户端不在本次匹配范围内。
