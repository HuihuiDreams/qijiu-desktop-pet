# 桌面宠物功能扩展 - 创意与实施规划

> 状态：Proposed（已提议，待实施）
> 最后更新：2026-05-10

---

## 一、背景与精炼 (Background & Refinement)

### 问题陈述
当前版本已实现了基础的养成系统（饱腹、灵力、心境、好感）和基础的 CP 互动。为了提升长期的用户留存率和应用的实用性，需要从“生产力工具”、“环境沉浸感”以及“玩法深度”三个维度进行扩展。

### 核心假设
- 用户希望桌宠不仅是装饰，还能提供一定的功能价值（如提醒工作、监控系统）。
- 更加逼真的环境交互（如感知窗口、同步天气）能显著提升“活着”的感觉。
- 收集系统（皮肤、插画）是驱动用户长期开启应用的核心动力。

### 排除的方向
- 暂不考虑大型 3D 场景开发。
- 暂不考虑多人联机社交功能。

## 二、功能规格 (Functional Specification)

根据初步构思，扩展功能分为以下三大板块：

### 1. 生产力工具化 (Productivity & Utility)
*   **“苍穹山派”番茄钟**：
    *   用户开启专注模式，角色进入“闭关”动画。
    *   沈九会监督用户，若频繁切换到非工作软件会触发“冷嘲热讽”对话。
*   **系统状态实时映射**：
    *   将 CPU/内存占用率映射为角色的“灵气流转”速度或特效强度。
    *   电量不足时，角色触发“灵力衰竭”提醒。
*   **宗门任务 (To-Do List)**：
    *   简单的待办事项管理，完成任务可获得“灵石”或好感度奖励。

### 2. 环境互动与沉浸感 (Environment & Immersion)
*   **窗口感知交互 (Window Awareness)**：
    *   角色可以在活动窗口的顶部“行走”或“坐下”。
    *   当用户最小化窗口时，角色表现出“寻找”或“无聊”的状态。
*   **时空同步系统**：
    *   根据用户本地天气（雨/雪/晴）显示对应的视觉特效 or 道具（如油纸伞）。
    *   深夜自动进入睡眠模式，切换为睡袍皮肤或关灯特效。

### 3. 收集与养成深度 (Gameplay & Collection)
*   **皮肤与配件系统 (Skins & Accessories)**：
    *   支持“不同时期”外观切换（如：弟子服、巅峰时期峰主服、现代 AU）。
    *   可互动道具：折扇（沈九专用）、玄肃剑（岳七专用）。
*   **随机奇遇与收藏**：
    *   触发罕见互动时，自动保存“回忆快照”到图鉴中。
    *   掉落随机系统任务（复刻原作设定）。

## 三、任务分解 (Task Breakdown)

### Phase 1：生产力与工具层 (Priority: High)
- **Task 1: 基础番茄钟实现**
  - 在右键菜单增加“开始闭关”选项。
  - 实现倒计时逻辑与闭关专属动画状态。
- **Task 2: 系统监控数据接入**
  - 引入 `node-os-utils` 获取 CPU 和内存信息。
  - 映射逻辑将系统状态传递给渲染进程。

### Phase 2：环境感知层 (Priority: Medium)
- **Task 3: 窗口边界检测**
  - 使用 `active-win` 获取焦点窗口坐标。
  - 优化 `MovementSystem`，使宠物能识别“平台”（窗口顶边缘）。
- **Task 4: 天气 API 对接**
  - 集成免费天气 API。
  - 为 `PetRenderer` 增加雨/雪粒子特效层。

### Phase 3：收集与美化层 (Priority: Low)
- **Task 5: 皮肤系统重构**
  - 在 `SpriteView` 中增加皮肤切换接口。
  - 准备“现代 AU”皮肤素材。
- **Task 6: 互动图鉴 (Gallery)**
  - 实现截图保存功能。
  - 增加“回忆录”UI 界面查看已解锁的插画。
