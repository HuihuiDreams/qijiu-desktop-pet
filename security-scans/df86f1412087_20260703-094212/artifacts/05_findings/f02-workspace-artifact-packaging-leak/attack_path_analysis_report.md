# 攻击路径报告：构建与推送规则会泄漏内部工作区与扫描产物

## 数据流
开发者本地 `.codex/**` / `security-scans/**` -> `package.json` 的宽泛打包规则 或 `push.ps1` / `push.sh` 的 `git add .` -> 发行包 / 远程仓库

## 可达性
- 触发者：普通开发者在有残留产物的工作树上执行本地构建或辅助推送脚本
- 入口：本地 `npm run build`、`electron-builder`、`./push.sh`、`./push.ps1`
- 结果：收到发行包或访问仓库的人可以看到内部迁移报告、扫描记录、临时工作树代码片段

## 影响
- 主要是信息暴露，而不是直接代码执行
- 若未来这些目录中出现凭据、令牌或更敏感的内部路径，影响会进一步上升
