# DeskPet: 岳七 & 沈九修仙桌宠 🗡️🪭

基于 Electron 构建的《人渣反派自救系统》主题桌面宠物应用。
岳清源（岳七）和沈清秋（沈九）将在你的桌面上陪伴你，自由漫步，甚至偶尔触发互动。

## 📦 软件下载与安装 (Download & Installation)

本应用支持 **Windows** 和 **macOS** 平台。你可以在 GitHub Releases 页面下载已打包好的安装包。

### 💻 Windows 平台
* **安装包**：下载 `desktop-pet-setup-x.y.z.exe`。
* **安装步骤**：双击运行安装程序，按照提示选择安装路径并完成安装即可。

### 🍎 macOS 平台
* **系统要求**：macOS 12.0 (Monterey) 及更高版本。
* **版本选择**：
  * **Apple Silicon 芯片**（M1 / M2 / M3 等）：下载 `desktop-pet-setup-x.y.z-arm64.dmg`。
  * **Intel 芯片**：下载 `desktop-pet-setup-x.y.z-x64.dmg`。
* **安装步骤**：
  1. 双击打开下载的 `.dmg` 磁盘映像。
  2. 将 **七九爱宠** 图标拖拽到右侧的 **Applications**（应用程序）文件夹中。
  3. 在“应用程序”中双击运行。
* **首次启动报错解决方法（绕过 Gatekeeper）**：
  由于应用未在 Apple 注册付费开发者证书，首次启动时系统可能会提示“无法验证开发者”或“已损坏，无法打开”。请通过以下方式解决：
  > [!IMPORTANT]
  > **方法一（推荐，系统设置中允许）**：
  > 1. 打开 Mac 的 **系统设置 -> 隐私与安全性**。
  > 2. 向下滚动到“安全性”板块，你会看到提示：*“已阻止使用“七九爱宠”，因为来自身份不明的开发者”*。
  > 3. 点击 **仍要打开** (Open Anyway)，输入 Mac 登录密码确认即可。
  >
  > **方法二（终端命令）**：
  > 1. 打开终端（Terminal）。
  > 2. 输入以下命令并回车：
  >    ```bash
  >    xattr -cr /Applications/七九爱宠.app
  >    ```
* **手动更新注意事项**：
  1. 先从托盘菜单点击 **退出**，确保旧版本已经完全关闭。
  2. 再打开新版 `.dmg`，将 **七九爱宠** 拖入 **Applications** 并选择替换旧版本。
  3. 如果替换后首次启动仍被系统拦截，请再次在“隐私与安全性”中点击 **仍要打开**，或运行上面的 `xattr -cr` 命令。

## 🚀 快速开始 (Quick Start)

1. 确保安装了 [Node.js](https://nodejs.org/)。
2. 安装依赖：`npm install`
3. 运行程序：`npm run dev`

程序启动后，两个角色会出现在你的桌面上。
- **左键按住拖曳**：可以在多显示器虚拟桌面范围内移动他们。
- **右键点击角色**：打开交互菜单。
- **系统托盘（右下角绿点）**：右键点击托盘图标可进行更多控制：
  - 桌宠功能与软件功能会用分割线分组显示，便于区分当前操作影响的是角色还是应用本身。
  - **📊 显示状态面板**：查看角色详细数值。
  - **🧘🏻‍♂️ 苍穹静修 / 🧘🏻‍♂️ 闭关中 N 分钟 / 🧘🏻‍♂️ 静修圆满**：打开番茄钟倒计时窗口；进行中和完成后托盘菜单会显示对应状态。
  - **🎨 切换皮肤**：切换已安装的角色皮肤，目前包含默认皮肤、鸟塑七九、猫兔七九，并在菜单中标注作者。
  - **⏸️ 暂停走动 / 🚶 恢复走动**：控制角色是否在桌面上自由漫步。
  - **👻 隐藏桌宠 / 👻 显示桌宠**：暂时隐藏所有角色（隐藏期间逻辑暂停，不消耗数值）。
  - **🔄 重置位置**：将所有角色重置到屏幕中央。
  - **🖥️ 切换屏幕**：在 macOS 多显示器环境中，将桌宠移动到指定的屏幕。
  - **⏰ 开启久坐提醒 / ⏰ 关闭久坐提醒**：开启或关闭久坐提醒。
  - **⏰ 提醒间隔**：设置提醒间隔（30、45、60、90、120 分钟）。
  - **🌤️ 开启天气同步 / 🌤️ 关闭天气同步**：开启或关闭现实天气感知功能。
  - **🌤️ 修改城市**：设置用于获取天气的城市。
  - **🪟 启用界面感知 / 🪟 禁用界面感知**：启用/禁用边界互动功能（仅 Windows/macOS 支持；不支持时显示 **🪟 界面感知暂不可用**）。
  - **🌐 语言**：在中文、英文、日文之间切换界面、托盘菜单、状态面板和提示弹窗。
  - **🚀 开机自动启动 / 🚀 禁用开机启动**：设置是否随系统登录自动运行。
  - **📦 检查更新**：手动检查 GitHub 上的新版本；Windows 安装版支持下载进度与自动升级，macOS 会引导到 Releases 手动替换安装。
  - **🛠️ 开发者工具**：仅在 `npm run dev` 开发态显示，用于打开 Electron 控制台进行调试；安装版不会显示该入口。
  - **❌ 退出**：完全关闭程序。
  - **🏷️ 版本**：在托盘菜单底部显示当前应用版本。

### 🖥️ 多显示器说明

- **状态面板窗口**：可以拖曳到副屏使用。
- **桌宠活动范围**：岳七和沈九会在所有已连接显示器组成的虚拟桌面范围内活动，支持走到或拖曳到副屏。
- **混合缩放支持**：在主屏/副屏缩放比例不同的 Windows 多显示器环境中，桌宠会按实际显示器工作区限制移动边界，并尽量保持角色、右键菜单和灵力特效的视觉大小一致。
- **边缘保护**：自动行走目标会避开副屏右边缘和下边缘之外的不可见区域；如果显示器布局变化，旧目标会被修正回当前可见区域。

### 🌐 多语言说明

- **支持语言**：中文、英文、日文。
- **实时切换**：通过托盘菜单切换语言后，主窗口、右键菜单、状态面板和更新弹窗会跟随刷新。
- **状态面板同步**：已经打开的状态面板会保留当前数值并立即重绘为新语言。

### 🎨 皮肤说明

- **内置皮肤**：默认皮肤、鸟塑七九、猫兔七九。
- **作者署名**：托盘皮肤菜单会显示皮肤名称与作者，例如“猫兔七九·紫萤 / Cat & Bunny - (Artist) Violetfirefly”。
- **统一动作资源**：皮肤会同步替换站立、行走、饥饿、睡眠、喂食、修炼、关怀、亲吻、拥抱、分享食物等动作表现。
- **资源回退**：如果某个皮肤缺少单个动作资源，渲染会尽量回退到默认资源，避免切换皮肤后出现空白。

### 📦 更新说明

- **Windows 自动更新**：安装版可通过托盘菜单检查 GitHub Releases，新版本会显示下载进度，下载完成后可选择重启并安装。
- **macOS 手动更新**：由于当前未使用 Apple Developer ID 证书，macOS 会显示当前版本和最新版本，并引导你打开 Releases 下载新版 DMG 后覆盖安装。
- **清晰错误提示**：网络错误、服务端不可用、下载中断和开发模式都会显示可理解的提示；开发态 `npm run dev` 不支持检查更新。

### 🪟 界面感知说明 (Realm Awareness)

- **窗口互动**：界面感知开启时，桌宠会识别当前活动窗口、任务栏或 macOS Dock 的边缘。
- **动态寻路**：他们空闲散步时，可能会走到当前窗口顶部、任务栏上方或 Dock 上方停留，看起来更像是在你的桌面环境里活动。
- **菜单控制**：你可以在托盘菜单中选择“启用界面感知”或“禁用界面感知”来切换。如果当前系统暂不支持该能力，菜单中会显示“界面感知暂不可用”。

### 🌤️ 天气感知与时空同步说明 (Weather Awareness & Time Sync)

- **本地时段**：桌宠会根据你电脑的本地时间，自动切换清晨、白天、黄昏、深夜四个时段。在深夜（00:00 - 04:59），他们会变得更加安静、更容易睡觉、减少四处走动，且有概率拒绝互动。
- **实时天气**：通过托盘菜单选择“🌤️ 开启天气同步”并配置你的城市后，桌宠会感知现实世界的真实天气情况（晴、阴、雨、雪等）。
- **天气互动**：雨雪天气会在屏幕上方下起轻量的粒子雨雪特效，并且角色有可能会触发特定天气的特殊对话。
- **隐私优先**：天气同步默认关闭。即使关闭或断网，本地时段的氛围变化依然生效。

### 🧘🏻‍♂️ 苍穹静修说明 (Pomodoro)

- **托盘入口**：从托盘菜单点击 **🧘🏻‍♂️ 苍穹静修** 打开番茄钟窗口；倒计时进行中会显示 **🧘🏻‍♂️ 闭关中 N 分钟**，完成后显示 **🧘🏻‍♂️ 静修圆满**。
- **时长输入**：输入本次专注分钟数；默认使用上次输入的分钟数，首次使用或非法输入时回退为 25 分钟。
- **专注窗口**：开始后桌面上的两位会进入倒计时窗口，窗口里显示倒计时、进度条和两个静止宠物；窗口默认置顶，可在窗口右上角点击 **取消置顶 / 置顶** 切换。
- **结束反馈**：完成后会显示一句温和鼓励文案；提前停止或关闭窗口会恢复到专注前的桌宠显示和走动状态。

### ⏰ 久坐提醒说明 (Break Reminder)

- **健康护航**：开启后，应用会在你连续活跃一段时间后提醒你起来走走。
- **互动表现**：提醒触发时，岳七和沈九会来到屏幕中间附近，显示休息提醒对话；你可以点击角色关闭提醒，或等待约 20 秒自动消失。
- **智能计时**：你可以在托盘菜单中设置 30、45、60、90 或 120 分钟的提醒间隔。锁屏、睡眠或离开电脑一段时间会自动重置计时；如果桌宠暂时隐藏，提醒不会弹出，会从下一轮重新开始计算。

### 📹 会议自动隐藏说明 (Meeting Auto-Hide)

- **Teams 优先**：当前主要按 Windows Teams 实测数据实现。检测到 Teams 会议活动时，桌宠会自动隐藏；会议结束后约 15 秒内恢复。
- **不打扰共享屏幕**：共享屏幕中也会保持隐藏，避免角色挡住会议内容或被共享出去。
- **手动状态优先**：如果你本来就是手动隐藏桌宠，会议结束后不会自动显示；如果你在会议隐藏期间通过托盘手动显示桌宠，会清除本次自动隐藏状态。
- **隐私边界**：检测只使用会议应用进程名和 UDP 端点数量，不读取会议标题、窗口标题、浏览器 URL、音视频内容或屏幕内容。
- **Zoom 暂未充分校准**：Zoom 已预留检测路径，但当前还没有足够实测数据；后续开会时可以继续用观测脚本校准阈值。

## 📊 养成系统 (Nurture System)

本游戏有四项核心“修仙”数值。游戏采用了**写实节奏**（每 5 分钟计算一次自然消耗），即使关闭程序，下次打开时也会**计算离线时间的消耗**！

### 1. ❤️ 好感 (Affection)
代表两人之间的羁绊。初始值为 0。长时间不互动好感度会自然下降，但通过简单的抚摸就能轻松补回。
好感度决定了他们碰面时能触发什么级别的互动。
* **自然消耗**：每 2 小时下降 1 点。
* **提升方法**：
  * 主动关怀：右键沈九选择“🤚 七哥关怀”，或右键岳七选择“🤚 小九撒娇”。
  * 自然增长：当他们在桌面上漫步并碰巧走到一起时，如果触发了“打招呼”、“分食物”或“一起修炼”等互动，好感度也会增加。
* **门槛解锁**：
  * 好感 `> 20`：解锁“一起修炼”。
  * 好感 `> 50`：解锁“拥抱”。
  * 好感 `> 70`：解锁“亲亲”。

### 2. 🍖 饱腹 (Hunger)
民以食为天。
* **自然消耗**：每 5 分钟下降 2 点（两人基础消耗相同）。
* **隐藏彩蛋（偏心机制）**：当两人靠近并触发“分享食物”互动时，岳七会把自己的食物偷偷塞给沈九。这会导致**岳七一次性扣除 5 点饱腹度**，而**沈九恢复 10 点饱腹度**。只有岳七当前饱腹度至少 5 点时才会触发分食，避免他已经饿到见底时还继续投喂。因此，如果他们经常凑在一起，岳七会饿得比沈九快得多！
* **提升方法**：右键点击角色选择“🍎 喂食”（恢复 25 点饱腹度）。
* **额外消耗**：右键选择“💤 休息”需要消耗 10 点饱腹度（辟谷需要消耗体力），并会恢复 15 点心境和 10 点灵力。如果饱腹度太低将无法休息。
* **负面影响**：如果饱腹度 `< 30`，会陷入饥饿状态，导致**心境加速下降**，并且角色会冒气泡抱怨。当饱腹度进一步降至 `< 25` 时，角色周围会触发橙色预警光晕。

### 3. ✨ 灵力 (Qi)
修仙者的精力。
* **自然消耗**：每 5 分钟下降 2 点（灵气自然流失）。
* **提升方法**：
  * 主动修炼：右键点击角色选择“🧘🏻‍♂️ 打坐修炼”，角色会原地打坐 30 秒，期间每秒恢复 1 点灵力。
  * 休息恢复：右键选择“💤 休息”可瞬间恢复 10 点灵力，同时恢复 15 点心境（但会消耗饱腹度）。
  * 互动恢复：如果两人走到一起触发“一起修炼”，双方按单人打坐的 1.5 倍恢复灵力，结果四舍五入。
* **负面影响**：如果灵力 `< 20`，会导致**心境加速下降**，并冒气泡提示。

### 4. 🧘🏻‍♂️ 心境 (Mood)
角色的心情和精神状态。
* **自然消耗**：每 5 分钟下降 2 点。
* **额外消耗**：太饿（饱腹 < 30）或太累（灵力 < 20）时，心境会额外加速掉落。
* **提升方法**：
  * 右键“喂食”或“关怀/撒娇”都会顺带提升一点心境。
  * 他们两人凑在一起产生的大部分互动（打招呼、拥抱等），都会提升双方的心境。

## 🎨 视觉特效 (Visual Effects)

除了属性面板，你还可以通过直接观察桌宠的外观来判断他们的状态：

* **周围发绿色光晕**：角色正在处于**打坐修炼**（Meditating）状态，此时他们的灵力会快速恢复。
* **周围发橙色光晕（脉冲闪烁）**：角色正处于**极度饥饿**（Hunger < 25）状态，需要尽快喂食。
* **身体变成半透明**：角色的**心境极其低落**（Mood < 25），由于过度劳累或饥饿导致情绪不佳。请尽快通过互动、喂食或关怀来安慰他们。
* **多屏一致性**：在不同缩放比例的显示器之间移动时，角色本体、右键菜单和灵力光晕会根据所在屏幕自动缩放并重新对齐中心点。

## 💡 游玩提示 (Tips)

1. **不要让他们太饿！** 饥饿会导致无法休息，还会让心情变得极差。
2. **顺其自然**：他们会在你的屏幕上自己走来走去，时不时闲聊两句。如果你把他们拖到一起（距离 180px 以内），就有机会触发 CP 互动对话和特效。
3. **互动有冷却**：触发一次互动后，会有 1 分钟的冷却时间，期间就算叠在一起也不会立刻触发下一次。
4. **互动会自动分开站位**：即使你把他们拖到完全重合，互动开始时也会自动拉开一点距离，避免亲亲、拥抱、打招呼等动画叠在一起。
5. **存档是自动的**：程序会自动保存他们当前的状态和位置，下次打开时无缝衔接。

## 🏗️ 架构 (Architecture)

整个应用基于 Electron 构建，分为主进程（Main Process）和渲染进程（Renderer Process）。核心逻辑（宠物移动、数值养成、状态机）在前端渲染进程中以 Game Loop 的方式驱动。
- 详细架构说明见：[docs/structure.md](./docs/structure.md)
- 重大架构决策见：[docs/decisions/](./docs/decisions/) 目录下的 ADRs。
