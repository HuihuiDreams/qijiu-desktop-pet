# DeskPet: 岳七 & 沈九修仙桌宠 🗡️🪭

基于 Electron 构建的《人渣反派自救系统》主题桌面宠物应用。
岳清源（岳七）和沈清秋（沈九）将在你的桌面上陪伴你，自由漫步，甚至偶尔触发互动。

## 🚀 快速开始 (Quick Start)

1. 确保安装了 [Node.js](https://nodejs.org/)。
2. 安装依赖：`npm install`
3. 运行程序：`npm run dev`

程序启动后，两个角色会出现在你的桌面上。
- **左键按住拖曳**：可以把他们移动到屏幕任何位置。
- **右键点击角色**：打开交互菜单。
- **系统托盘（右下角绿点）**：右键点击托盘图标可进行更多控制：
  - **显示/隐藏状态面板**：查看角色详细数值。
  - **恢复/暂停走动**：控制角色是否在桌面上自由漫步。
  - **显示/隐藏桌宠**：暂时隐藏所有角色（隐藏期间逻辑暂停，不消耗数值）。
  - **🚀 开机自动启动**：设置是否随系统登录自动运行。
  - **⬆️ 检查更新**：手动检查 GitHub 上的新版本并自动升级（仅限安装版本）。
  - **🔄 重置位置**：将所有角色重置到屏幕中央。
  - **🛠️ 开发者工具**：打开 Electron 控制台进行调试。
  - **❌ 退出**：完全关闭程序。

## 📊 养成系统 (Nurture System)

本游戏有四项核心“修仙”数值。游戏采用了**写实节奏**（每 5 分钟计算一次自然消耗），即使关闭程序，下次打开时也会**计算离线时间的消耗**！

### 1. ❤️ 好感 (Affection)
代表两人之间的羁绊。初始值为 0。**好感度不会自然下降。**
好感度决定了他们碰面时能触发什么级别的互动。
* **提升方法**：
  * 主动关怀：右键沈九选择“🤚 七哥关怀”，或右键岳七选择“🤚 小九撒娇”。
  * 自然增长：当他们在桌面上漫步并碰巧走到一起时，如果触发了“打招呼”、“分食物”或“一起修炼”等互动，好感度也会增加。
* **门槛解锁**：
  * 好感 `> 20`：解锁“一起修炼”。
  * 好感 `> 50`：解锁“拥抱”。
  * 好感 `> 70`：解锁“亲亲”。

### 2. 🍖 饱腹 (Hunger)
民以食为天。
* **自然消耗**：每 5 分钟下降 2 点（两人基础消耗相同）。
* **隐藏彩蛋（偏心机制）**：当两人靠近并触发“分享食物”互动时，岳七会把自己的食物偷偷塞给沈九。这会导致**岳七一次性扣除 10 点饱腹度**，而**沈九恢复 15 点饱腹度**。因此，如果他们经常凑在一起，岳七会饿得比沈九快得多！
* **提升方法**：右键点击角色选择“🍎 喂食”。
* **额外消耗**：右键选择“💤 休息”需要消耗 10 点饱腹度（辟谷需要消耗体力）。如果饱腹度太低将无法休息。
* **负面影响**：如果饱腹度 `< 30`，会陷入饥饿状态，导致**心境加速下降**，并且角色会冒气泡抱怨。

### 3. ✨ 灵力 (Qi)
修仙者的精力。
* **自然消耗**：每 5 分钟下降 1 点（灵气自然流失）。
* **提升方法**：
  * 主动修炼：右键点击角色选择“🧘🏻‍♂️ 打坐修炼”，角色会原地打坐 30 秒，期间快速恢复灵力。
  * 休息恢复：右键选择“💤 休息”可瞬间恢复 30 点灵力（但会消耗饱腹度）。
  * 互动恢复：如果两人走到一起触发“一起修炼”，双方都会大量恢复灵力。
* **负面影响**：如果灵力 `< 20`，会导致**心境加速下降**，并冒气泡提示。

### 4. 🧘🏻‍♂️ 心境 (Mood)
角色的心情和精神状态。
* **自然消耗**：每 5 分钟下降 1 点。
* **额外消耗**：太饿（饱腹 < 30）或太累（灵力 < 20）时，心境会额外加速掉落。
* **提升方法**：
  * 右键“喂食”或“关怀/撒娇”都会顺带提升一点心境。
  * 他们两人凑在一起产生的大部分互动（打招呼、拥抱等），都会大幅提升双方的心境！

## 🎨 视觉特效 (Visual Effects)

除了属性面板，你还可以通过直接观察桌宠的外观来判断他们的状态：

* **周围发绿色光晕**：角色正在处于**打坐修炼**（Meditating）状态，此时他们的灵力会快速恢复。
* **周围发橙色光晕（脉冲闪烁）**：角色正处于**极度饥饿**（Hunger < 30）状态，需要尽快喂食。
* **身体变成半透明**：角色的**心境极其低落**（Mood < 25），由于过度劳累或饥饿导致情绪不佳。请尽快通过互动、喂食或关怀来安慰他们。

## 💡 游玩提示 (Tips)

1. **不要让他们太饿！** 饥饿会导致无法休息，还会让心情变得极差。
2. **顺其自然**：他们会在你的屏幕上自己走来走去，时不时闲聊两句。如果你把他们拖到一起（距离 180px 以内），就有机会触发 CP 互动对话和特效。
3. **互动有冷却**：触发一次互动后，会有 20 秒的冷却时间，期间就算叠在一起也不会立刻触发下一次。
4. **存档是自动的**：程序会自动保存他们当前的状态和位置，下次打开时无缝衔接。

## 🏗️ 架构 (Architecture)

整个应用基于 Electron 构建，分为主进程（Main Process）和渲染进程（Renderer Process）。核心逻辑（宠物移动、数值养成、状态机）在前端渲染进程中以 Game Loop 的方式驱动。
- 详细架构说明见：[docs/structure.md](./docs/structure.md)
- 重大架构决策见：[docs/decisions/](./docs/decisions/) 目录下的 ADRs。
