# Good Omens: 克劳利 & 亚茨拉斐尔 好兆头桌宠 🕶️🪽

基于 Electron 构建的经典奇幻作品《好兆头》（*Good Omens*）主角 **克劳利（Anthony J. Crowley）✖️ 亚茨拉斐尔（Aziraphale）** 好兆头桌宠应用。
恶魔与天使将在你的桌面上陪伴你，自由漫步，施展奇迹，甚至偶尔触发甜度超标的专属互动。

---

## 角色人设与专属机制 (Characters & Features)

| 角色 | 身份与标志 | 日常充能行为 | 专属互动倾向 |
| :--- | :--- | :--- | :--- |
| **克劳利 (Crowley)** | 恶魔、深红与墨黑、黑色宾利、墨镜蛇瞳 (🕶️ / 🐍) | **🪴 养植物 (Tending Plants)**<br>手持喷水壶严肃巡视盆栽，训诫植物 *“GROW BETTER!”* | 投喂方、守护方，为天使搜罗丽兹酒店的美食与可丽饼；分食消耗自身饱腹度 |
| **亚茨拉斐尔 (Aziraphale)** | 天使、米白与浅金、伦敦旧书店、热可可与甜点 (🪽 / 📖) | **📖 静心研读 (Reading)**<br>戴上老花镜翻阅珍稀初版书，安详轻啜大吉岭红茶 | 吃货被投喂方、品味红酒与法式甜点，过饱时体面解开扣子揉肚子；夜间梦话发起方 |

### 核心机制与原作彩蛋

1. **丽兹投喂与体面吃撑 (`shareFood` / `throwup`)**：
   - 恶魔克劳利带回丽兹酒店的新鲜烘焙甜点投喂天使；
   - 亚茨拉斐尔过饱时触发老派英国绅士/天使的体面吃撑名场面——解开马甲下摆扣子揉肚子微喘，克劳利在一旁无奈抱臂扶额。
2. **专属日常充能与奇迹能量 (`cultivate` / `meditate` / 25-Lazarus Miracle)**：
   - **恶魔照料植物（克劳利）**：手持喷水壶巡视盆栽并厉声训诫（*“GROW BETTER!”*）。这是恶魔标志性的解压与精神充能日常，在发泄日常烦闷与确立恶魔威严的同时，抚平体内躁动的暗火魔力，高效重聚并恢复奇迹能量；
   - **天使静心研读（亚茨拉斐尔）**：在 Soho 珍本书店的扶手椅上品茶研读初版古籍。在纯粹静谧的阅读心流中洗涤凡尘杂念，与天界最初的圣洁秩序共鸣调息，从而迅速充盈圣光神力；
   - **联合施展奇迹**：致敬原作经典“25 级拉撒路联合奇迹”，两人并肩汇聚圣光与暗火能量（双方各消耗 10 点奇迹能量，需双方当前奇迹均至少 10 点），大幅提升双方心境（+12）与羁绊（+6）。
3. **好感度阶梯关系渐进 (`minAffection`)**：
   - 互动严格对应跨越六千年的关系渐进：日常拌嘴 (`0`) → 丽兹投喂 (`0`) → 秘密协定与奇迹同行 (`20`) → 战火相拥 (`50`) → 跨越神魔戒律的深情一吻 (`75`)。
   - 高好感度 (`>= 80`) 解锁专属梦境与温柔守护梦话联动。
4. **创世流星雨天气 (`weather.rain`)**：
   - 将雨天升级为晨星天使造星名场面（Starmaker Meteor Shower），漫天流星金光划过，亚茨拉斐尔抬起洁白羽翼为克劳利遮挡星尘。
5. **伦敦旧书店研读番茄钟 (`pomodoro`)**：
   - 亚茨拉斐尔的 A.Z. Fell and Co. 伦敦旧书店伴读模式，留声机古典乐与壁炉余烬微光氛围。
6. **屏保幽会被撞见 (`screensaverCaught`)**：
   - 晃动鼠标打断屏幕中央的漫步或依偎时，克劳利慌忙扶正墨镜假装履行恶行，亚茨拉斐尔心虚藏起小蛋糕辩称“常规阵营交涉”。

## 📦 软件下载与安装 (Download & Installation)

本应用支持 **Windows** 和 **macOS** 平台。你可以在 GitHub Releases 页面下载已打包好的独立安装包。

### 💻 Windows 平台
* **系统要求**：Windows 10 / 11（64 位）。不支持 Windows 7 / 8 / 8.1 及 32 位系统。
* **安装包**：下载 `good-omens-pet-setup-x.y.z.exe`。
* **安装步骤**：双击运行安装程序，按照提示完成安装。

### 🍎 macOS 平台
* **系统要求**：macOS 12.0 (Monterey) 及更高版本。
* **版本选择**：
  * **Apple Silicon 芯片**（M1 / M2 / M3 / M4 等）：下载 `good-omens-pet-setup-x.y.z-arm64.dmg`。
  * **Intel 芯片**：下载 `good-omens-pet-setup-x.y.z-x64.dmg`。
* **安装步骤**：
  1. 双击打开下载的 `.dmg` 磁盘映像。
  2. 将 **GoodOmensDeskPet** 图标拖拽到右侧的 **Applications**（应用程序）文件夹中。
  3. 在“应用程序”中双击运行。
* **首次启动提示无法验证开发者时（绕过 Gatekeeper）**：
  > [!IMPORTANT]
  > **方法一（推荐，系统设置中允许）**：
  > 1. 打开 Mac 的 **系统设置 -> 隐私与安全性**。
  > 2. 向下滚动找到提示：*“已阻止使用“GoodOmensDeskPet”，因为来自身份不明的开发者”*。
  > 3. 点击 **仍要打开** (Open Anyway)，输入密码确认即可。
  >
  > **方法二（终端命令）**：
  > ```bash
  > xattr -cr /Applications/GoodOmensDeskPet.app
  > ```

## 🚀 基础操作与托盘控制

- **左键按住拖曳**：在多屏幕虚拟桌面范围内移动克劳利与亚茨拉斐尔。
- **右键点击角色**：打开交互菜单（投喂甜点、养植物/静心研读、关怀与休息）。
- **系统托盘图标（好兆头桌宠）**：
  - **📊 显示状态面板**：查看饱腹度、奇迹能量、好感度与心境数值。
  - **📏 调整大小…**：自由调整体型，支持实时预览与保存。
  - **📖 A.Z. Fell & Co. 静心研读**：开启伦敦旧书店番茄钟倒计时。
  - **🎨 选择皮肤…**：打开可视化皮肤画廊。
  - **⏸️ 暂停走动 / 🚶🏻‍♂️ 恢复走动**：控制角色漫步。
  - **👻 隐藏桌宠 / 👻 显示桌宠**：暂时隐藏所有角色。
  - **🔄 重置位置**：一键将角色重置到当前屏幕中央。
  - **⏰ 开启久坐提醒**：支持 30 ~ 120 分钟多档位久坐关怀。
  - **💕 开启高甜屏保**：支持空闲自动进入双人屏保模式。
  - **🌤️ 天气同步**：绑定城市天气，下雨时触发创世流星雨特效与专属对白。
  - **🌐 语言切换**：支持纯正英式英语（English Ground Truth）、简体中文（zh）与 Amazon Prime 官方规范日语（日本語）。
  - **🚀 开机自动启动**：随系统登录自动启动常驻。

## 🛠️ 本地开发与测试 (Development)

```bash
# 安装依赖
npm install

# 启动开发环境（带独立 QA 数据隔离）
DESKTOP_PET_USER_DATA_DIR=~/.deskpet-good-omens-dev npm run dev

# 运行全量单元测试
npm test

# 运行真实 Electron 冒烟测试
npm run qa:electron:smoke

# 打包预检与构建
npm run verify:installer
npm run protect:assets
npm run build
npm run verify:package
```
